Контрольные вопросы

1. Что такое HTML-форма?
HTML-форма — элемент страницы для ввода и отправки данных пользователем.

2. Для чего используется тег form?
Тег form объединяет элементы формы и задает способ и адрес отправки данных.

3. Разница GET и POST?
GET передает данные в URL, а POST отправляет данные в теле запроса.

4. Какие бывают input?
Например: text, password, email, number, date, checkbox и radio.

5. Что делает required?
Делает поле обязательным для заполнения.

6. Зачем textarea?
Textarea используется для ввода многострочного текста.

7. Как работает select?
Select создает список вариантов, из которого пользователь выбирает значение.

8. Что такое HTML-валидация?
HTML-валидация — проверка введенных данных браузером до отправки формы.

9. minlength vs maxlength?
minlength задает минимальную длину значения, а maxlength — максимальную.

10. Можно ли отправить форму без JS?
Да. HTML5 позволяет выполнить базовую проверку и отправить форму без JavaScript.
